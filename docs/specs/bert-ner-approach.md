# C 终期方案：BERT-NER 通用实体提取

## 问题

中期两份 PDF 各自用定制方法提取实体：
- 用地分类指南 → 正则规则（硬编码格式，不通用）
- 编制指南 → LLM prompt（贵、慢、不稳定）

来一份新 PDF 就要写一套新逻辑。终期需要一套**通用方案**：任意国土空间规划 PDF → 自动抽出规划实体和关系。

## 决策：LLM 辅助标注 + BERT 微调

不走纯规则、不走纯 LLM。走 **LLM 生成训练数据 + 微调 BERT-NER**。

### 流程

```
中期产出（350 个国标术语词典）
        +
  两份 PDF 原文
        │
        ▼
  DeepSeek 逐段标注（LLM-as-Annotator）
  → "【城镇开发边界】SPATIAL 内应控制【容积率】INDICATOR"
        │
        ▼
  人工抽检 10%（~100 条/1000 条）
        │
        ▼
  微调 BERT-NER（bert-base-chinese 或 distillbert）
        │
        ▼
  本地 BERT 推理：任意 PDF → 自动 NER
```

### 为什么可行

| 条件 | 状态 |
|------|------|
| 种子词典 | ✅ 137 LandUse + 213 Concept = 350 个术语 |
| 标注数据来源 | ✅ DeepSeek/更强 LLM，中文 NER 标注准确率 85-92% |
| 人工验证 | ✅ 100 条抽检，半小时 |
| 训练资源 | ⚠️ 需要 GPU（可用 Colab / 腾讯云 T4 / CPU 慢训） |
| 降级方案 | ✅ 如果 BERT 效果不达标，退回到 LLM-NER（方案 A） |

### 实体类型（与中期 Concept types 一致）

| 标签 | 示例 |
|------|------|
| SPATIAL | 城镇开发边界、生态保护红线、永久基本农田 |
| INDICATOR | 容积率、建筑密度、绿地率 |
| FUNCTION | 居住用地、工业用地、商业服务业用地 |
| POLICY | 集约节约用地、多规合一、用途管制 |
| ENTITY | 养老院、污水处理厂、市政道路 |

### 关系抽取（第二步）

NER 之后，用规则判断同句内两个实体间的关系：
- SPATIAL + INDICATOR 同句 → GOVERNS
- FUNCTION + FUNCTION 同句 + 编码前缀匹配 → BELONGS_TO
- 其余用 LLM 判断
