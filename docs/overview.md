## 关键技术决策

| 决策 | 选择 | 为什么 |
|------|------|--------|
| 向量存储 | SQLite + numpy BLOB | 零配置，答辩现场无需网络 |
| Embedding | TF-IDF + jieba | 先跑通，BERT 为终期升级项 |
| 图数据库 | Neo4j Community 5.26.4 | 内置可视化，答辩 demo 效果好 |
| LLM | DeepSeek V4 Flash | OpenAI 兼容，低成本 |
| 后端 | Node.js + Express | 与前端同语言，TypeScript 全栈 |
| 预处理 | Python 离线脚本 | 答辩前预跑一次，不做上传界面 |
