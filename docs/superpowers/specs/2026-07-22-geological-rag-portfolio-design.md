# 地质知识图谱与 RAG 项目作品集设计

## 目标与受众

为求职和面试场景制作一套可直接上传至招聘平台的项目作品材料，展示「地质知识图谱与 RAG 增强智能问答系统」的业务价值、技术架构、工程难点和个人贡献。

作品集将项目定位为小组协作背景下，由本人覆盖或主导几乎全部关键模块的全链路工程项目。表述使用「全链路项目负责人 / Full-stack & AI Engineering」，不把团队成果虚构为完全独立开发。

## 最终交付物

输出目录：`portfolio/geo-knowledge-rag/`

1. `地质知识图谱与RAG项目封面.png`
   - 1600 × 900，16:9。
   - JPG 或 PNG，文件小于 4 MB。
   - 用于招聘平台的「图片作品」。
2. `地质知识图谱与RAG项目作品集.pdf`
   - 8–10 页，文件小于 20 MB。
   - 用于招聘平台的「附件作品」。
3. `作品上传文案.txt`
   - 作品名称。
   - 350 字以内项目描述。
   - GitHub 链接。
   - 附件与隐私说明。
4. 作品链接：`https://github.com/winter-street/geo-knowledge-qa`

## 内容结构

PDF 每页只回答一个核心问题，顺序如下：

1. 项目封面与一句话定位。
2. 业务问题：普通 LLM 为什么不适合直接回答地质找矿问题。
3. 解决方案：RAG、Neo4j、LLM 与 GIS 的协同架构。
4. 离线数据处理：PDF、Chunk、TF-IDF/BGE、NER、Neo4j 与 OWL。
5. 在线问答链路：并行检索、证据融合、LLM 生成与 SSE 流式输出。
6. 产品体验：问答、溯源、地图和知识图谱可视化。
7. 个人贡献：架构、前端、后端、数据处理、知识图谱、评测和交付。
8. 技术难点与解决方案。
9. 测试、回答忠实性评测与隐私处理。
10. 技术栈、GitHub 项目仓库和 GitHub 个人主页。

## 视觉设计

采用「技术地图封面 + 学术案例研究内页」的混合方向。

### 封面

- 深墨蓝合成地质底图。
- 森林绿知识图谱节点。
- 矿物金色检索路径。
- 细密坐标网格和克制的技术标注。
- 不使用科技蓝渐变、发光球、真实卫星影像或真实矿区坐标。

### PDF 内页

- 暖白学术报告底色。
- 深色衬线标题与清晰的无衬线正文。
- 使用架构图、流程图、合成界面图和贡献矩阵作为主要证据。
- 不使用装饰性卡片堆叠，保持信息层级和阅读节奏。

### 配色

- 深墨蓝：`#172733`
- 森林绿：`#2E7D5B`
- 矿物金：`#B58A3A`
- 暖白：`#F7F5EF`

## 素材与数据策略

- 项目描述、技术架构和代码事实来自当前工程及公开版 GitHub 仓库。
- 系统界面使用公开版代码中的合成 mock 数据，或重新绘制脱敏界面。
- 架构图、离线流程图和在线问答流程图重新绘制。
- 封面采用原创合成视觉，不使用真实矿区地图或真实运行数据。
- 不展示真实文献标题、原文片段、数据库条目、API Key、密码、本机路径、精确坐标和课程私有附件。
- 可使用技术类别和定性结果，但不披露真实数据规模及敏感统计。

## 个人贡献表述

重点呈现以下全链路工作：

- 设计 RAG + 知识图谱双路检索架构。
- 完成或深度参与 Vue 前端、Express 后端和 Flask 检索微服务。
- 实现 JWT、SSE 流式问答、文献溯源、地图和图谱交互。
- 构建 PDF 解析、Chunk、TF-IDF/BGE、地质 NER 和 Neo4j 写入流程。
- 建立 Mineral、Rock、Structure、TimePeriod、DepositType 地质实体 Schema。
- 实现 OWL 本体推理和回答忠实性评测。
- 负责跨服务联调、脱敏发布和课程交付整理。

## 生成流程

1. 从公开源码和脱敏项目说明提炼内容。
2. 生成并压缩 1600 × 900 项目封面。
3. 绘制架构图、离线管线、在线问答链路和贡献矩阵。
4. 生成 8–10 页 PDF。
5. 生成招聘平台上传文案。
6. 渲染并逐页检查 PDF，检查封面尺寸与文件大小。
7. 执行敏感信息扫描和最终文件清单核验。

## 验收标准

- 封面尺寸为 1600 × 900，文件小于 4 MB。
- PDF 为 8–10 页，文件小于 20 MB。
- 中文字体正常，无文字截断、重叠和空白页面。
- GitHub 链接清晰可读。
- 项目描述与当前代码事实一致，不夸大个人贡献。
- 所有界面、实体、坐标和问答示例均为脱敏或合成内容。
- 不包含真实数据、凭证、本机路径或私有课程附件。
